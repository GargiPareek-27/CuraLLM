# CuraLLM web app

Next.js (App Router) chat page that talks to the CuraLLM API.

Status: **chat page written; build and lint not yet verified.** It shows whatever the API returns, including a "Demo response" badge while the mock model is active. Sources are empty until retrieval exists (Phase 2).

## Run it

1. Start the backend from the repo root (see `docs/RUNBOOK.md`): `scripts/dev` then `scripts/migrate`.
2. In this folder:

```
npm install
npm run dev
```

3. Open http://localhost:3000. Use `localhost`, not `127.0.0.1`: the API only allows the origin `http://localhost:3000` (`CORS_ORIGINS`).

The API address defaults to `http://127.0.0.1:8000`. To change it, set `NEXT_PUBLIC_API_URL` before starting (PowerShell: `$env:NEXT_PUBLIC_API_URL="http://127.0.0.1:8000"`).

## Checks

```
npm run lint
npm run build
```

Both run in CI (`.github/workflows/web.yml`).

## Notes

- `AGENTS.md` is generated by Next.js for AI coding tools and is kept so `git status` stays clean after `next dev`.
- Conversation history is held in memory only. Persistence arrives with accounts (Phase 4).
